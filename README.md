# معراب (M3rab Desktop Clone)

تطبيق سطح مكتب ويندوز مستنسخ بالكامل من تطبيق **معراب** (الإصدار الأصلي الرسمي 1.0.85).

## المكونات
- **الواجهة الأمامية (Renderer):** مبنية بـ React 19 + Framer Motion مع كافة الأصول، الخطوط، وتصاميم معراب الأصلية.
- **العملية الرئيسية (Main Process):** [`main.cjs`](./main.cjs) توفر كافة واجهات الـ IPC وجسور الاتصال المتوافقة مع `preload.cjs`.
- **كتالوج الألعاب:** يحوي 107+ لعبة معربة مدعومة تلقائياً من بوابة Cloudflare Gateway ومكتبة Steam.

## تشغيل التطبيق
يمكنك تشغيل البرنامج المكتبي مباشرة عبر:
- النقر المزدوج على [`start.bat`](./start.bat)
- أو تشغيل الأمر:
```bash
npx electron main.cjs
```
